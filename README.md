# Python Practice - ЗАДАЧИ ДЛЯ ТРЕНИРОВКИ

## Правила

1. **ИИ (ChatGPT, Claude и др.) запрещён для написания кода.**
   Использовать ИИ можно ТОЛЬКО чтобы узнать, что означает 
   команда или синтаксис (например: "как работает input() 
   в Python"). Полный код задачи ИИ писать не должен, 
   логику собираешь сам.

2. Каждую задачу делай в соответствующем файле (task_1.py, 
   task_2.py и т.д.)

3. Задачи идут по возрастанию сложности, не пропускай 
   вперёд, если предыдущая не получилась.

4. После выполнения каждой задачи - отдельный коммит 
   с понятным названием (например: "complete task 1", 
   не "фикс" или "готово").

5. Если застрял, то не сиди часами в тупике. Спроси меня, 
   или спроси ИИ ТОЧЕЧНО про конкретную команду 
   (правило 1).
